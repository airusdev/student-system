# Student Management System
A CLI-based student record system built in C

What it can do:
1. Add Students
2. View in sorted list (choose between Name or GPA)
3. Custom Search: choose between partial name, min/max gpa, or gpa range

How to compile:
gcc student_system.c -o student_system
./student_system

What I learned:
I've learned many things just as it had me frustrated. There were days I just didn't want to code at all.

I learned a lot of structs, pointers, and memory.
I've also implemented quicksort algorithm from scratch and implemented my own general quicksort algorithm.
